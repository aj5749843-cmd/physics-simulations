# المحاكاة في الفيزياء باستخدام CK-12

لكل درس في الفيزياء محاكاة تفاعلية مجانية وفيديو يشرح استخدامها، مع خرائط مفاهيم للربط مع التخصصات الأخرى.

**الفصول:** الكهرباء التيارية · دوائر التوالي والتوازي · المجالات المغناطيسية · الحث الكهرومغناطيسي · الكهرومغناطيسية · الفيزياء النووية · الذرة

**إعداد:** أ. أريج الجبرتي

> المحاكاة ومقاطع الشرح مصادر تعليمية مجانية من موقع CK-12 وتفتح على الموقع نفسه.

## حقيبة أنشطة التعلم التكيفي

في مجلد [`adaptive`](adaptive/) حقيبة ثانية فيها ١٥ مفهومًا علميًا في أربعة مجالات، ولكل مفهوم رابط لتدريب CK-12 التكيفي، مع تتبّع لإنجاز الطالب.
